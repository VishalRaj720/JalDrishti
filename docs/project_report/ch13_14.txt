## Annexure A: Database Tables and Migrations

The main database tables are:

- **users, orgs:** accounts (with home block and email opt-in) and organisations
- **districts, blocks, aquifers:** administrative and aquifer geometry
- **monitoring_wells, water_samples, monitoring_stations:** measured data, with the source of every row
- **data_sources, dataset_versions:** checksums and versions of loaded files
- **isr_points:** hypothetical sites with operating settings and injection start date
- **scenarios, simulation_runs:** saved scenarios and runs, with plume geometry, timeline frames, vertical screening and the model version used
- **advisories:** screenings with their status (draft, published, withdrawn)
- **alerts, alert_deliveries, block_subscriptions:** alerts with tier and explanation, the email delivery log, and residents’ followed blocks
- **field_observations:** submissions from field officers and their review
- **audit_log:** record of every important action (cannot be edited or deleted)

The schema was built through 26 Alembic migrations, from 0001_initial to 0026_alert_tiers_and_explanation. Important steps included: 0004 (wells and samples), 0007 (organisations, provenance and audit log), 0009 (row-level security), 0011 (fix of swapped district coordinates), 0012 (simulation runs), 0017 (advisories), 0018 (resident alerts), 0022 (single admin and restored regulator role), 0025 (home block and email delivery log) and 0026 (alert tiers and explanations).

### C.1 Plume shape: Ogata–Banks and Domenico factors (ml_pipeline/physics/transport.py)

```python
def _ogata_banks_second_term(X, Xc, aL):
    """Second Ogata-Banks (1961) term (comment shortened)."""
    expo = X / aL
    safe = (expo < 700.0) & (X > 0.0)
    arg2 = (X + Xc) / (2.0 * np.sqrt(aL * Xc))
    return np.where(safe, 0.5 * np.exp(np.where(safe, expo, 0.0)) * erfc(arg2), 0.0)


def _long_factor(X: np.ndarray, Xc: float, aL: float) -> np.ndarray:
    Xc = max(Xc, 1e-3)
    aL = max(aL, 1e-3)
    return np.clip(0.5 * erfc((X - Xc) / (2.0 * np.sqrt(aL * Xc)))
                   + _ogata_banks_second_term(X, Xc, aL), 0.0, 1.0)


def _tran_factor(X: np.ndarray, Y: np.ndarray, aT: float, W: float) -> np.ndarray:
    aT = max(aT, 1e-4)
    Xpos = np.where(X > 0.1, X, 0.1)
    tw = 2.0 * np.sqrt(aT * Xpos)
    return 0.5 * (erf((Y + W / 2.0) / tw) - erf((Y - W / 2.0) / tw))
```

### C.2 Dual-porosity slowing: the retarded clock (ml_pipeline/physics/transport.py)

```python
def apparent_retardation(t_days: float, beta: float, omega: float) -> float:
    """R_app(t) = 1 + beta*(1 - e^(-a t)), a = omega*(1+beta)/beta.
    [Goltz & Roberts 1986] (comment shortened)"""
    if beta <= 0.0 or omega <= 0.0:
        return 1.0
    a = omega * (1.0 + beta) / beta
    return 1.0 + beta * (1.0 - math.exp(-a * max(t_days, 0.0)))


def retarded_clock(t_days: float, beta: float, omega: float) -> float:
    """Closed-form I(t) = int_0^t dt'/R_app(t') [days] (comment shortened)."""
    t = max(t_days, 0.0)
    if beta <= 0.0 or omega <= 0.0:
        return t
    a = omega * (1.0 + beta) / beta
    I = t / (1.0 + beta) + math.log1p(-beta * math.expm1(-a * t)) / (a * (1.0 + beta))
    if not math.isfinite(I) or I < 0.0:                # unreachable by construction
        raise ValueError(f"retarded_clock non-finite: t={t}, beta={beta}, omega={omega}")
    return I
```
